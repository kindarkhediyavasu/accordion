HTML stands for HyperText Markup Language. It is used to create and structure content on web pages.
HTML5 is the modern version of HTML. It introduced semantic elements such as <header>, <nav>, and <article>, along with multimedia elements like <audio> and <video>, improved form controls, and other modern web capabilities.
Semantic elements clearly describe the meaning and purpose of their content to both developers and browsers. Examples include <header>, <nav>, <main>, <section>, <article>, and <footer>. They improve code readability, accessibility, and SEO.
<div> is a generic block-level container used to group larger sections of content, while <span> is a generic inline container used to group or style a small portion of text or inline content.
Block-level elements generally start on a new line and, by default, take up the available width. Inline elements generally flow within the surrounding text and take only the space required by their content.
Void elements are HTML elements that cannot contain child content and do not have closing tags. Examples include <img>, <input>, <br>, <hr>, <meta>, and <link>.
<!DOCTYPE html> tells the browser to use standards mode and indicates that the document is an HTML5 document. It should be placed at the beginning of the HTML file.
An id is intended to uniquely identify a single element within a document, while a class can be shared by multiple elements. Both can be used for CSS and JavaScript, but classes are commonly used for reusable styling.
Both async and defer allow external scripts to download without blocking HTML parsing. An async script executes as soon as it finishes downloading, so execution order is not guaranteed. A defer script executes after HTML parsing is complete and preserves the order of deferred scripts.
data-* attributes allow us to store custom data directly on HTML elements. JavaScript can access this data using the element's dataset property.
Accessibility means designing web pages so they can be used by everyone, including people who use screen readers, keyboards, or other assistive technologies. We can improve accessibility by using semantic HTML, proper labels, meaningful alt text, and keyboard-friendly interactions.
ARIA stands for Accessible Rich Internet Applications. It provides additional accessibility information for assistive technologies when native HTML semantics are not sufficient. However, native semantic HTML should be preferred whenever possible.
CSS specificity is the set of rules the browser uses to decide which CSS rule should be applied when multiple rules target the same element. Generally, inline styles have higher priority, followed by IDs, then classes, attributes, and pseudo-classes, and finally element selectors.ARIA stands for Accessible Rich Internet Applications. display: none removes the element from the layout, so it does not take up any space. visibility: hidden hides the element but it still occupies its original space in the layout.
relative keeps the element in the normal document flow and allows it to be visually offset from its original position. absolute removes the element from the normal flow and positions it relative to its nearest positioned ancestor. fixed positions the element relative to the viewport, so it stays fixed during scrolling. sticky behaves like a normal element until a specified scroll threshold is reached, after which it sticks within its scroll container.
The CSS Box Model describes how the browser calculates the size and space of an element. It consists of content, padding, border, and margin. By default, width and height apply to the content area, but with box-sizing: border-box, padding and border are included within the specified width and height.
z-index controls the stacking order of elements, but it works within stacking contexts. A higher z-index does not always appear above another element if the elements belong to different stacking contexts. Properties such as positioned elements with z-index, transform, opacity, and others can create stacking contexts.
CSS inheritance is the process where some CSS properties are automatically passed from a parent element to its children. Properties such as color and font-family are commonly inherited, while properties like margin, padding, and border are generally not inherited.
CSS variables, also called custom properties, allow us to store reusable values such as colors, fonts, spacing, and sizes. They are defined using -- and accessed using the var() function. They help make CSS more reusable, maintainable, and useful for features like theming.
Pseudo-elements are CSS keywords that allow us to style or insert content into a specific part of an HTML element without adding an extra HTML element. They are written using ::, such as ::before, ::after, ::first-letter, and ::first-line.
Hoisting is JavaScript's behavior where declarations are processed before the code executes. var declarations are hoisted and initialized with undefined, while let and const are also hoisted but remain in the Temporal Dead Zone until their declaration is reached.
The Temporal Dead Zone, or TDZ, is the period between entering a block scope and the point where a let or const variable is initialized. Accessing the variable during this period results in a ReferenceError.
A closure occurs when an inner function remembers and can access variables from its outer function's scope even after the outer function has finished executing.
undefined usually means a value has not been assigned, while null is an intentional representation of no value.
The Event Loop is the mechanism that allows JavaScript to handle asynchronous operations even though JavaScript executes JavaScript code on a single main thread. It checks whether the call stack is empty and then moves eligible tasks from queues into the call stack for execution.
All three methods allow us to explicitly set the value of this. call() accepts arguments individually, apply() accepts arguments as an array-like value, and bind() returns a new function with this permanently bound to the provided object.
The main difference is how they handle this. A normal function gets its own this depending on how it is called, while an arrow function does not have its own this; it inherits this from its surrounding lexical scope. Arrow functions also cannot be used as constructors with new.
Event capturing is when an event travels from the outer ancestor toward the target element. Event bubbling is when the event travels from the target element back toward its ancestors. Event listeners use bubbling by default unless capturing is enabled.
Event delegation is a technique where we attach a single event listener to a parent element instead of attaching separate listeners to each child. It works because events bubble from the child to the parent. It is especially useful for dynamically created elements and can reduce the number of event listeners.
A shallow copy creates a new outer object, but nested objects or arrays can still reference the same underlying objects. A deep copy creates independent copies of nested data as well.
